# Documentation Index

- `developer_overview.md`: High-level architecture and runtime model, including LDtk as the map source of truth and LDtk `spriteEditor` as the gameplay-entity body-animation/body-hitbox and weapon-attack-hitbox source.
- `AnimationAndHitboxes.md`: Where player/entity sprite animations and hitboxes are defined and resolved, including the runtime LDtk `spriteEditor` path for gameplay body animation/body boxes and weapon attack hitboxes, typed-LDtk placement-sprite overrides, authored conventions for inclusive bbox bounds, right-facing bbox source data, and required `0` thresholds.
- `AnimationEditorUI.md`: Implementation-ready UI specification for a standalone editor that creates, edits, validates, and previews entity/weapon animation and hitbox data in the runtime format.
- `AnimationEditorTaskBreakdown.md`: Project-manager task plan with phased backlog, dependencies, estimates, QA gates, and release criteria for implementing the standalone animation editor.
- `AnimationEditor.md`: Implemented standalone editor architecture, route map, modules, save behavior, repository-mode browser requirements, responsive-shell behavior (including compact collapsed tablet navigator rail badge/capsule tokens), inspector terminology polish (friendly labels + grouped X/Y inputs), follow-up intuitiveness updates (consistent keyframe wording, summary-only timeline card, friendly issue-path labels, clearer mode naming, copy feedback, flex-wrapped X/Y rows for narrow widths), and local commands for `tools/animation-editor`.
- `PixelboxRuntime.md`: Phaser compatibility-layer details, including LDtk-backed map loading, runtime-parsed `spriteEditor` animation/body-box/attack-box data, typed-LDtk-entity to legacy-sprite normalization, sidecar compat metadata merging for LDtk round-trips, compatibility map virtualization, fixed-aspect integer scaling behavior, bitmap-font text rendering (`setCharset` support), dialog wrapping behavior, and automation hooks.
- `Audio.md`: Manifest format and runtime audio mapping.
- `MapConverter.md`: Legacy Pixelbox -> LDtk migration workflow, including official LDtk 1.5.3 project generation, typed LDtk entity definition emission, level-layout preservation during regeneration, preserved/seeding/backfilled LDtk `spriteEditor` data for gameplay entities and weapon attacks, `maps.ldtk.meta.json` sidecar extraction, real tileset dimension extraction, compat metadata packing, entity field serialization, and runtime-preserved logical map names.
- `EntityPlacement.md`: LDtk entity-layer placement model, typed entity catalog, runtime sprite mappings, and required metadata fields.
- `PlatformerMapGenerator.md`: Standalone procedural platformer map generator API, discrete movement math, takeoff-window route validation, height-aware vertical archetypes, late-section verticality quotas, aerial-segment variation controls, optional platform metadata, PNG rendering helper, and the root smoke-test command.
